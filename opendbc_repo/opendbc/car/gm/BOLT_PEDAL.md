# Bolt pedal and conventional-cruise configurations

The 2017, 2018–21 and 2022–23 conventional-cruise Bolt configurations and the 2022–23 ACC-pedal configuration have separate owners. Normal CAN/firmware identification remains available. A supported live pedal sensor (`0x201`, bus 0) selects the interceptor branch; an identified Bolt EUV or 2022–23 ACC Bolt with that sensor is mapped to `CHEVROLET_BOLT_ACC_2022_2023_PEDAL`. The current interface does not require a saved `GMPedalLongitudinal` opt-in. `DisableOpenpilotLongitudinal` is a separate startup preference that defaults off; stock restoration depends on the actual selected topology and camera evidence.

The interceptor branch uses paired pedal tracks for acceleration and a regenerative paddle/PRNDL scheduler for braking. Its active pedal and scheduler commands require fresh stock L with ManualMode clear, healthy current sensor/source packets, active longitudinal controls and no driver gas, brake or paddle override. This restriction belongs to the interceptor/scheduler branch. The separate conventional-cruise controller, including the 2018–21 `0xC120`/`0xC121` profiles, accepts Drive or Low and controls speed through stock cruise buttons rather than pedal actuation.

The ACC-pedal branch additionally requires fresh confirmation that stock ACC is disengaged and retains stock cancellation. It can send qualified friction-brake commands on the powertrain bus, including low-speed braking and a bounded zero-brake unwind. The non-ACC interceptor branches use regenerative braking without that friction sender. None of these branches sends ASCM gas/regen commands. A fault, stale sensor, stock takeover or control release withdraws active pedal requests; scheduler release feeds remain conditional on actual L ownership. Driver paddle or gear changes discard pending active scheduler feeds.

Native safety independently checks the selected profile, pedal pairing/CRC/counter, source freshness, scheduler payload and ownership, and applicable numeric command bounds. Existing tests join generated DBC parsing, controller output and native safety. The separate gateway Volt Auto Hold feature does not change these Bolt branches or their regenerative stopping behavior.
